NEKTO LOCAL

Start your local dashboard

The chat browsers run on your computer. Start the helper, then open your dashboard.

  1. Install and start Docker Desktop.
  2. In the extracted package, open start-windows.cmd on Windows or start-macos.command on macOS. On Linux, run bash start-linux.sh.
  3. Wait for the build to finish. The first start downloads the browser and can take several minutes.
Open dashboard

Keep Docker running. No dashboard password is needed. In Audio, use “IP браузера” to check each connected browser’s public IP.
